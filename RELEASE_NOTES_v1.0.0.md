# v1.0.0

Initial code/provenance release for the human evolutionary-functional boundary manuscript. Contains author-owned code with MIT scope restricted to code/, archived small summary tables, selected frozen contracts and reproducibility metadata. No raw data, third-party source workbooks, reference sequences or binaries are redistributed. Private path prefixes and host-specific executable defaults were removed from release derivatives and documented; scientific code bodies and result values remain unchanged. No new scientific analysis was executed. Historical environments and reference dependencies are not represented as fully portable. The version-specific Zenodo DOI reserved for this release is 10.5281/zenodo.22705327; registration occurs upon publication of the associated Zenodo record.
